# Examples

Full applications built on react-native-gpui live in their own repositories and install the
library from npm. Conformance fixtures stay in `ts/examples/`.

| Example | What it shows |
| --- | --- |
| [chatterino-gpui](https://github.com/felipe-software/chatterino-gpui) | A Chatterino-style Twitch chat client: tabs, a split grid, emotes, badges, history |
